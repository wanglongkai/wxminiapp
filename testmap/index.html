接入天地图

天地图 JS API 需要开发者密钥（tk）。请前往 天地图控制台 申请「浏览器端」应用密钥，填入下方即可加载地图。密钥仅保存在本机 localStorage。

提示：在小程序 web-view 中正式使用时，需将 api.tianditu.gov.cn 与 t0~t7.tianditu.gov.cn 配置为业务域名；开发者工具勾选「不校验合法域名」可直接调试。
